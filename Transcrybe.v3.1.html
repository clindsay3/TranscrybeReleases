Transcrybe 3.1

Added Danish and Swedish live transcription and translation on Macs running macOS 26.5 or later. Added keyboard shortcuts for switching directly to microphone or All Applications audio. Added Show on All Spaces, making it easy to keep subtitle windows visible when switching desktops or entering full screen. Expanded the available subtitle font size range. Improved Speech Analyzer revisions and finalization for more stable live captions. Improved translation stability during live captions and language changes on macOS 26. Improved issue reporting with diagnostics and a support email option. Additional stability improvements and bug fixes.
